**12 de agosto de 2026**

### Añadido

- Estructura separada para guías, referencia de la API e historial de cambios.
- Configuración central para adaptar el portal a la identidad de una empresa.
- Contenido inicial con convenciones de autenticación, respuestas y errores de la API.

### Cómo usar este historial de cambios

Crea un archivo para cada versión o fecha relevante en `src/content/docs/changelog/`. Registra los cambios que afecten a integraciones existentes, como:

- endpoints nuevos, modificados o descontinuados;
- campos y comportamientos cambiados;
- cambios de autenticación, límites o requisitos de seguridad.
