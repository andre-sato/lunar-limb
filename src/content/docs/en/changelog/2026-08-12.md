**August 12, 2026**

### Added

- Separate structure for guides, API reference, and changelog.
- Central configuration for adapting the portal to a company identity.
- Initial content covering API authentication, responses, and errors.

### How to use this changelog

Create a file for every relevant version or date in `src/content/docs/changelog/`. Record changes that affect existing integrations, such as:

- new, changed, or deprecated endpoints;
- modified fields and behaviors;
- changes to authentication, limits, or security requirements.
