**12 de agosto de 2026**

### Adicionado

- Estrutura separada para guias, referência de API e changelog.
- Configuração central para adaptar o portal à identidade de uma empresa.
- Conteúdo inicial com convenções de autenticação, respostas e erros de API.

### Como usar este changelog

Crie um arquivo para cada versão ou data relevante em `src/content/docs/changelog/`. Registre mudanças que afetem integrações existentes, como:

- endpoints novos, alterados ou descontinuados;
- campos e comportamentos modificados;
- alterações de autenticação, limites ou requisitos de segurança.
