term: RAG
aliases:
  - Retrieval-Augmented Generation
  - Retrieval Augmented Generation
caseSensitive: true
---
Técnica que combina recuperação de trechos de uma base de conhecimento com
geração de texto por um modelo de linguagem. A resposta é redigida pelo modelo,
mas ancorada nos trechos recuperados.
